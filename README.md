# 🐴 金马踏春·2026

一个基于"马走日"规则的2026马年主题益智小游戏。

## 🎮 游戏简介

在2026年农历丙午年（马年），你将扮演天庭的"金马驹"，在除夕之夜下凡，将"福气"洒满人间大地。你需要在有限的步数内，踏遍地图上的每一个角落，收集所有福气，最终抵达终点。

## ✨ 游戏特色

- 🐎 **经典规则**：基于中国象棋"马走日"的移动规则
- 🧧 **春节主题**：喜庆的国潮卡通风格，充满节日氛围
- 🎯 **益智解谜**：需要规划路径，避免陷入死角
- 📱 **移动优先**：完美适配手机屏幕，单手即可操作
- 🎨 **精美动画**：流畅的动画效果和视觉反馈
- 🎵 **音乐音效**：春节主题背景音乐和灵动炫酷的音效

## 🎯 游戏规则

1. **移动方式**：小马按照"日"字形移动（类似象棋中的马）
2. **收集福气**：踩到红色的福字格子即可收集
3. **到达终点**：收集完所有福字后，到达马厩（终点）即可过关
4. **障碍物**：石头无法通过，且会"蹩马腿"（如果马腿位置有障碍，该方向无法跳跃）
5. **有效移动**：蓝色高亮的格子表示可以移动的位置

**注意**：游戏已启用"蹩马腿"机制，所有关卡都经过验证确保可解。

## 🕹️ 操作说明

- **移动**：点击蓝色高亮的格子即可移动小马
- **撤销**：点击"撤销"按钮可以回退上一步
- **重新开始**：点击"重新开始"按钮重置当前关卡
- **提示**：点击"提示"按钮查看操作提示
- **音乐控制**：点击🎵按钮切换背景音乐，点击🔔按钮切换音效
- **音量调节**：拖动🔊音量滑块调节整体音量（0-100%）

## 🚀 快速开始

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器：
   ```bash
   # 使用 Python
   python -m http.server 8000

   # 使用 Node.js
   npx serve
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 🎨 技术实现

- **纯前端**：HTML5 + CSS3 + JavaScript
- **无依赖**：不需要任何第三方库
- **响应式**：自适应各种屏幕尺寸
- **动画效果**：CSS3 动画和过渡效果
- **音频系统**：Web Audio API 生成音乐和音效
- **粒子特效**：Canvas 2D 实现的粒子系统

## 🎯 关卡设计

- **第1关**：初试马蹄 - 新手教学关卡（8x8格子）
- **第2关**：石阵迷踪 - 引入障碍物
- **第3关**：福满人间 - 复杂路径规划
- **第4关**：马踏迷宫 - 迷宫挑战
- **第5关**：福气满满 - 更多福字收集

## 🔧 开发者工具

### 关卡验证
在URL后添加 `?debug=true` 可以验证所有关卡是否可解：
```
http://localhost:8000?debug=true
```
打开浏览器控制台查看验证结果。

### 配置选项
在 `game.js` 中可以调整以下配置：
- `CELL_SIZE`: 格子大小（默认55px）
- `ENABLE_BLOCK_CHECK`: 是否启用"蹩马腿"机制（默认true）

## 📝 开发说明

游戏核心算法：
- 马走日移动验证：`abs(dx) + abs(dy) == 3 && dx != 0 && dy != 0`
- 蹩马腿检测：检查移动路径中间格子是否有障碍
- 路径规划：玩家需要避免把自己困在死角
